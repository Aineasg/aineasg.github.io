NET.OPEN-SOURCE

Tongfang Control Centre

When the manufacturer's software is locked-down and poorly built, the fix is to reverse-engineer the firmware and write something better.

Tongfang / Aistone Laptop Control Centre
View on GitHub ↗
BIOS Reverse Engineering Embedded Controller Open Source Rust ACPI

Tongfang and Aistone laptops are niche, enthusiast-grade machines with poor official control software. I reverse-engineered the Embedded Controller firmware protocol by analysing ACPI tables and diffing EC register states, then built an open-source replacement that gives the user real control over their own hardware.

Per-key RGB backlight control
Custom fan curve tuning by temperature
Direct EC register communication via ACPI
Power profile switching
Written in Rust, fully open source
Does what the OEM refused to build
